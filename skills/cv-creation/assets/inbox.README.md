# Inbox — drop files here

Put source materials here. The agent reads from this folder (it does not invent files for you).

| Subfolder | What to put |
| :--- | :--- |
| `resumes/` | Master CV / resume (PDF, DOCX, or Markdown) |
| `linkedin/` | LinkedIn profile export or a pasted text dump saved as `.md` / `.txt` |
| `from-links/` | Pages or files you (or the agent) saved from a URL you approved |

Tips:

- Prefer one clear master resume file (e.g. `resumes/master-resume.pdf`).
- For LinkedIn: paste text into `linkedin/linkedin-paste.md` if you cannot export a file.
- After dropping files, tell the agent: **ingest from inbox** (evidence-bank).
- Tailored application drafts live under `applications/`, not here.
