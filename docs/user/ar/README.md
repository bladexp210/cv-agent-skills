# مهارات الوكيل للسيرة الذاتية — وثائق المستخدم (العربية)

> **اتجاه القراءة:** هذه الصفحة بالعربية الفصحى وتُقرأ من اليمين إلى اليسار. أوامر الطرفية ومسارات الملفات وكتل الشيفرة تبقى كما هي (يسار–يمين داخل السياج).

**ما هذا؟** مهارات قابلة للتثبيت وفق معيار [Agent Skills](https://agentskills.io/home) — مهارات الوكيل (Agent Skills) — لبنك حقائق خاص (`evidence-bank` / بنك الحقائق) ومسار سيرة ذاتية لكل وظيفة (`cv-creation` / مسار السيرة الذاتية).

**الخطوة التالية:** افتح [`quick-start.md`](quick-start.md) (≈5 دقائق)، أو اختر موجّه التثبيت أدناه.

| الموقف | النتيجة | افتح | التوصية |
| :--- | :--- | :--- | :--- |
| عميل Agent Skills **و** استعداد لتثبيت بايثون ومكتباته وأدوات المطوّر ذات الصلة (أول مرة) | المهارات مُثبَّتة + تحقق/تصدير **قابل للتكرار** عبر سكربتات محلية | [`../../../prompts/ar/install-full.md`](../../../prompts/ar/install-full.md) | **فضّل Full** عندما يتوفر العميل ومكدس بايثون معاً. |
| عميل Agent Skills **لكن** لا تستطيع أو لا تريد تثبيت ذلك المكدس من بايثون (أول مرة) | المهارات تُحمَّل في الوكيل؛ المخرجات غالباً من الوكيل (يمكن صقل Markdown في Word / Docs / LibreOffice). ضمانات السكربتات أضعف | [`../../../prompts/ar/install-lite.md`](../../../prompts/ar/install-lite.md) | **فضّل Lite** عندما لديك عميل لكنك ترفض أو لا تستطيع تثبيت بايثون. |
| **بلا** عميل Agent Skills — روبوت محادثة في المتصفح فقط | ميجا-برومبت منظّم + حفظ الملفات خارج المحادثة | [`web-chat.md`](web-chat.md) | استخدم محادثة الويب **فقط** عندما لا يوجد عميل مهارات. |
