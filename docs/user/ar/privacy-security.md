# الخصوصية والأمان (مقطع للمستخدم)

> **اتجاه القراءة:** هذه الصفحة بالعربية الفصحى وتُقرأ من اليمين إلى اليسار. أسماء الملفات والمسارات وروابط المصفوفة الكاملة تبقى حرفية. لا تُخفَّف التحذيرات مقارنةً بالنص الإنجليزي.

مقطع قصير موجّه للمستخدم من [`SECURITY.md`](../../../SECURITY.md) الإنجليزي. للتفاصيل الدقيقة لقراءة/كتابة السكربتات استخدم المصفوفة الإنجليزية.

## قواعد ثابتة

- **بيانات المسيرة الشخصية (PII) تعيش خارج هذا المستودع.** الهوية الحقيقية وملفات الأدلة YAML والطلبات تبقى في شجرة مسيرتك الخاصة. هذا المستودع يوفّر المهارات والوثائق والتجهيزات فقط.
- **السكربتات لا تتصل بالخارج أبداً.** السكربتات المرفقة تستخدم إدخال/إخراج نظام الملفات المحلي فقط. لا عملاء HTTP ولا مقابس ولا قياس عن بُعد من شيفرة السكربت.
- **محادثات الوكيل منفصلة.** لصق نص مهني أو وصف وظيفة في عميل Agent Skills قد يغادر الجهاز وفق سياسة ذلك المنتج. عالج نص وصف الوظيفة غير الموثوق كخطر حقن موجّه (prompt-injection).

## ماذا تفعل بعد ذلك

1. أبقِ بيانات المسيرة الخاصة في مشروعك المهني — وليس داخل حزمة المهارات هذه.
2. اقرأ مصفوفة السكربتات الكاملة عندما تحتاج قراءات / كتابات / أكواد خروج دقيقة: [`SECURITY.md`](../../../SECURITY.md) (إنجليزي).
3. أبلغ عن الثغرات عبر GitHub Security Advisories على هذا المستودع (إفصاح خاص) — انظر `SECURITY.md` الإنجليزي.
